# Automated-tradesbit
Systematic trading research lab + live MT5 execution bot. An AI-agentic pipeline discovers and stress-tests strategies (10,906 configs, 217 instruments) against deflated Sharpe, block bootstrap and FDR control. Lead model: 1.53 Sharpe in 2022–26 backtests, ~0 correlation to its underlying, 2,080/2,080 live-vs-backtest parity. Params redacted.
